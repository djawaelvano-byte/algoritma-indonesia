1. Tulis pseudocode

Gunakan satu perintah pada setiap baris. Klik Jalankan untuk melihat hasil.

Perintah yang didukung
  • ALGORITMA Nama dan SELESAI (opsional)
  • TULIS "teks", variabel untuk menampilkan hasil
  • BACA namaVariabel untuk meminta input
  • namaVariabel ← ekspresi atau namaVariabel = ekspresi untuk memberi nilai
  • JIKA kondisi MAKA, JIKA TIDAK, dan AKHIR JIKA
  • Ekspresi: angka, teks, +, -, *, /, perbandingan > < = >= <=, DAN, ATAU

Ini interpreter pembelajaran sederhana, bukan penerjemah semua bahasa pemrograman. Perulangan dan fungsi belum didukung.

2. Input program
